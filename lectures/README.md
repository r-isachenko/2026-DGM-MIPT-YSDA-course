## Запуск

Версия Node задана в [.nvmrc](.nvmrc), зависимости — в lock-файле.
Из корня репозитория:

```sh
cd lectures
npm ci
npm run dev -- 1
```

Номер после `--` выбирает лекцию. По умолчанию — 1. Для лекции N используется
порт 3030 + N. В каждой папке лекции основной файл называется `slides.md`.

## Сборка и PDF

Перед build/export остановить dev-серверы общего проекта. Для выбранной лекции:

```sh
npm run finalize -- 1
```

Команда проверяет Slidev-исходник, идентификаторы слайдов, явные числа кликов,
разделы README, изображения с записанными источниками и общие макросы;
запускает тесты, собирает веб-версию и один PDF: `lectureN/LectureN.pdf`.
В PDF каждый логический слайд показан один раз, с полным раскрытием материала.
Пошаговые раскрытия сохраняются в браузерной презентации.
Экспорт проверяет число страниц по `slides.md` и заменяет итоговый файл только
после успешной проверки. Временные файлы находятся в игнорируемом `output/`.
`lectures/merged/` команда не меняет.

Отдельные этапы: `npm run check -- 1`, `npm run build -- 1`,
`npm run export -- 1`, `npm run test:demos`.

Для визуальной проверки всех страниц:

```sh
python tools/render-qa.py 1
```

Нужны Python-пакеты `pypdf`, `pypdfium2`, `Pillow`. Скрипт проверяет число страниц,
извлекает текст и создаёт контактные листы в `output/qa/lecture1/`.
Рендер QA, браузерные инспекторы и визуальный просмотр не входят в `finalize`.
Контактные листы помогают проверить все страницы; плотные места смотреть крупно.

После экспорта снова запустить `npm run dev -- 1`. При работающем сервере:

```sh
node tools/inspect.mjs 1
node tools/inspect-demos.mjs 1
```

`inspect.mjs N` проверяет раскрытия по `slides.md` и границы содержимого;
сценарии пера в нём сейчас покрывают Lecture 1. Для демо выбирать инспектор
соответствующей лекции из разделов ниже. `SLIDEV_QA_URL` меняет адрес сервера.
`SLIDEV_BROWSER_PATH` задаёт путь к Chromium-браузеру; по умолчанию инспекторы
используют Yandex в macOS. Инспекторы проверяют реализованные сценарии и не заменяют
визуальный просмотр; при изменении механизма сверять охват с кодом в `tools/`.

Dev-серверы разных лекций можно запускать параллельно: у каждой свой порт,
generated-файлы и кэш Vite в `lectureN/node_modules/.vite`, заданный общей темой.
Перед build/export по-прежнему останавливать dev-серверы; сборку и экспорт
выполнять последовательно.

## Структура

- `package.json`, lock-файл и `node_modules/` — общие для курса.
- `theme/` — локальная тема. Она подключает базовые стили theme-default,
  затем оформление курса; содержит `global-top.vue`, панель пера и компоненты.
- `theme/setup/macros.json` — единый редактируемый источник математических макросов.
- `theme/assets/` — общие редактируемые SVG taxonomy.
- `lectureN/slides.md` — текст, формулы, раскрытия и заметки преподавателя.
  В headmatter: `theme: ../theme`.
- `lectureN/public/figs/` — локальные иллюстрации; в слайдах `src="/figs/name.png"`.
  Общие SVG подключает `TaxonomyDiagram` из темы через явные импорты;
  Использовать `class="taxonomy"` для размера эталонной Lecture 1.
  Выделение задаётся флагами `autoregressive`, `normalizing-flow`,
  `variational-autoencoder`, `generative-adversarial-network`, `score-matching`,
  `denoising-diffusion`, `continuous-normalizing-flow`, `sde-based-diffusion`,
  `flow-matching`, `discrete-diffusion` или `absorbing-diffusion`.
- `lectureN/components/` и `lectureN/lib/` — компоненты и расчёты демонстраций.
  После переноса разделов Lecture 5 импортирует discriminator из `lecture4/components/`,
  Lecture 6 — Langevin из `lecture5/components/`, а Lecture 7 — forward diffusion
  из `lecture6/components/`; исходники демо сохраняются в этих папках.
  Демо clean data / noise / reverse mean перенесено в `lecture8/components/NoisePredictionDemo.vue`;
  его расчёты и состояние находятся в `lecture8/lib/`, формулы выводятся через `L8Math`.
- Метаданные слайда: уникальный `id`, целочисленный `clicks ≥ 0`;
  переходы Outline также содержат `section` с названием раздела.
  Проверки читают эти данные напрямую через установленный парсер Slidev.
- `tools/` — общие команды, тесты и проверка PDF.
- `deferred/kl/` — сохранённый оригинал KL-демо; его копия используется в Lecture 5.
  [Заметки по повторному использованию](deferred-demos.md).

Для итогового списка использовать `class: summary` в метаданных слайда.
Общая тема распределяет свободную высоту между пунктами через
`justify-content: space-between` — аналог `\vfill` между пунктами в LaTeX.
Работает и с Markdown-списком, и с `<ul>`; локальные отступы пунктов не нужны.

## Пометки занятия

Панель доступна постоянно в presenter mode или с `?tools`, без hover.
**Pen**, четыре цвета, **Undo**, **Redo**, **Save**, **Restore**, **Save & clear**.
Кнопки имеют область касания не менее 44 × 44 CSS px при масштабе 1.

- **Save** скачивает отдельный JSON со SVG-пометками всех слайдов. Сохранить
  его вместе с версией исходника лекции, использованной на занятии.
- **Save & clear** сначала скачивает архив сессии, затем очищает текущий слайд.
  Проверить загрузку файла перед закрытием браузера; браузер может блокировать
  автоматические скачивания. Остальные слайды сохраняются.
- **Restore** проверяет формат, название лекции, число слайдов и допустимое
  содержимое SVG. Если уже есть пометки, сначала скачивает текущую сессию,
  затем восстанавливает загруженную. SVG-архив не содержит историю Undo/Redo:
  после Restore она начинается заново, старые штрихи можно очистить целиком.
- Пометки относятся к логическому слайду и сохраняют координаты при раскрытиях.
  После изменения текста или геометрии слайдов старый архив может не совпасть:
  название и число слайдов не являются проверкой версии содержания.
- Автосохранение на диск отключено. До закрытия страницы или
  остановки сервера нужно нажать Save. `sessions/` исключена из Git.
- Статическая сборка не предоставляет сервер для синхронизации разных устройств.
  Проверка реального пера, проектора и сетевой схемы ещё нужна.

## Интерактивная Lecture 4

- Слайд 14: фиксированный encoder, Gaussian / Matched prior; Marginal KL,
  mutual information и средний conditional KL. Смена prior сохраняет MI.
- Слайд 23: определение quantization и интерактивная двумерная схема:
  восемь нерегулярно расположенных кодов, границы Voronoi и перемещаемая точка.
  Кнопок и настроек нет; для клавиатуры доступны стрелки и Home на выбранной точке.
  Следующие клики показывают collapse на фиксированном облаке encoder outputs
  и переинициализацию одного неиспользуемого кода: используются 2 → 3 из 8 кодов.
  Это иллюстрация; переинициализация не имитирует полный цикл обучения.
- Слайд 25: пространственный Forward — тензор векторов → карта индексов →
  lookup общего codebook → тензор для декодера.
- Слайд 26: путь forward и копирование градиента в straight-through estimator
  раскрываются штатными кликами вместе с существующим выводом.

PDF Lecture 4 содержит сравнение prior; схема quantization сохраняет
облако, старую позицию перезапущенного кода и число использованных кодов до/после. Состояние
управления сохраняется при возврате на слайд. Управлять в выводимом на экран
окне; синхронизация компонентов между presenter/viewer не реализована.
При включённом пере график квантования остаётся доступен для пометок,
а перетаскивание точки отключено.

Численные проверки: `node --test tools/test-latent-demos.mjs` (также входят

## Интерактивная Lecture 5

- Слайд 13: Gaussian data/model densities и точный оптимальный discriminator;
  ползунок среднего generator, Separated / Overlap / Matched и Reset.

- Слайд 19: одна Gaussian-модель для смеси двух Gaussians — ползунки Mean / Std. deviation,

- Слайд 26: компактная интерактивная схема на месте исходной картинки рядом с постановкой —

  и четыре раскрытия сохранены; отдельного продолжения нет. PDF показывает θ = 1.5,

- В PDF показаны оба подготовленных решения: forward KL и один симметричный минимум reverse KL.

## Интерактивная Lecture 6

- Слайд 16: Langevin dynamics на энергетическом ландшафте — Noise off / Noise on, Run / Pause, Step, Reset.
  Точный score двумерной Gaussian mixture, 192 частицы, фиксированный шаг η = 0.04
  и воспроизводимый шум. Смена режима начинает с тех же частиц; уход со слайда
  ставит симуляцию на паузу. Лимит — 300 шагов; PDF сравнивает режимы после 300.

- Слайд 30: три равновероятные чистые точки и перемещаемое шумное наблюдение при σ = 1.
  Клики показывают conditional scores, posterior weights с формулой Байеса,
  marginal score и posterior mean по Tweedie. Итог — усреднение чистых точек
  с posterior weights; среднее может лежать между модами. Between modes / Near left / Near right, Reset; точку можно
  перетаскивать или двигать стрелками и Home после фокуса. Точные значения вычисляются
  аналитически; это иллюстрация, без обучения сети. При включённом пере перетаскивание
  отключено, график доступен для пометок, кнопки остаются доступны.
- PDF сохраняет все четыре раскрытия Tweedie; в раздатке видна полная схема.
  Состояние управления сохраняется при возврате. Управлять в выводимом на экран
  окне; синхронизация с presenter/viewer не реализована.

Численные проверки: `node --test tools/test-score-demos.mjs` (также входят
в `npm run test:demos` и `finalize`). Браузерные сценарии:
`node tools/inspect-score-demos.mjs` при работающих Lectures 6 и 7 (forward diffusion).

## Интерактивная Lecture 7

- Слайд 13: прямая Gaussian diffusion для смеси двух одномерных Gaussians,
  постоянный β = 0.01. Ползунок t = 0…1000, четыре пресета и Reset. Слева исходная
  плотность, справа текущая маргинальная плотность и эталон N(0,1); отдельно показаны
  коэффициент сигнала и стандартное отклонение добавленного шума.

- Слайд 22: известное / неизвестное чистое значение в точном двухточечном примере.
  Выбор x₀ = −2 / 2, ползунок шумного наблюдения и Reset.
  Всегда видны две плотности: q(xₜ₋₁ | xₜ) и q(xₜ₋₁ | xₜ, x₀) для выбранного x₀.
  Веса смеси подписаны как вероятности q(x₀ = −2 / 2 | xₜ).
- Слайд 24: общий timestep для linear-beta / cosine schedules; график log-SNR
  и две версии одной кодом нарисованной цифры с одним фиксированным Gaussian noise.
  Ползунок t = 1…1000, Reset к t = 500. Цветовая шкала изображения фиксирована.
- Слайды 26–27: нативные схемы forward encoder и reverse decoder / latent prior;
  подсветка синхронизирована с обычными кликами. Та же цепочка на слайдах 32–33
  связывает reconstruction / prior matching / denoising со слагаемыми ELBO.

PDF сравнивает forward diffusion при t = 0 / 75 / 250 / 1000 на одном слайде,
показывает Gaussian при x₀ = −2 вместе со смесью при xₜ = 0, сравнение
schedules при t = 500. Состояния контролов
сохраняются при уходе и возврате. Управлять в выводимом на экран окне;
синхронизация presenter/viewer не реализована. Ресурсы работают без внешней сети.

Численные проверки: `node --test tools/test-diffusion-demos.mjs` (включены в
`test:demos` и `finalize`). Браузер: `node tools/inspect-diffusion-demos.mjs 7`.

## Интерактивная Lecture 8

- Слайд 14: три связанные скалярные оценки при фиксированных xₜ и t.
  Выбор выхода сети (clean data / noise / reverse mean) сохраняет все значения;
  движение любой ручки выбирает соответствующий выход и пересчитывает остальные.
  Компактные карточки переключают выход сети и подсвечивают соответствующую строку

  Ниже приведены три эквивалентные записи noise-MSE с весами для чистых данных и reverse mean.
- Слайд 30: одна диаграмма общей шумовой траектории и DDIM-шагов для двух
  равновероятных чистых точек x₀ = −1 / +1. Forward paths: одна текущая точка,
  два возможных продолжения и их Bayes weights; раскрытие x₀ меняет условное
  будущее, сохраняя текущее наблюдение. How DDIM moves: один переход через
  пять отдельных стадий — предсказать пару, зафиксировать путь, выбрать меньший
  шум, переместить точку, затем пересчитать оценки. Переход сохраняет старые
  оценки и кривую; отдельный вызов denoiser меняет их при неподвижной новой точке.
  Начальное наблюдение фиксировано: xₜ = 0.35 при u = 1 − ᾱ = 0.5; целевой
  уровень uₛ = 0.1. Есть Back, Replay step и Reset, ползунка нет. Это локальное
  семплирование с промежуточного уровня и аналитическим MSE denoiser.
  PDF сохраняет неизвестное прошлое и один завершённый DDIM-переход с фиксированной
  парой и численной формулой. Алгоритм далее сохранён на слайде 31.
- Слайд 42: нормированная плотность при фиксированном уровне шума в одномерном
  примере с Gaussian mixture. Видны unconditional / conditional / scaled densities;
  выбор класса, γ = 0…7, пресеты 0 / 1 / 3 / 7 и Reset. График показывает
  плотность на выбранном уровне шума; конечная плотность полного sampler не задаётся.
- Слайд 47: CFG в пространстве scores. Ползунок γ = 0…5, пресеты
  0 / 0.5 / 1 / 3 и Reset. Две базовые стрелки фиксированы; γ меняет
