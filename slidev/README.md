# DGM course in Slidev

Общий проект курса. Первая лекция перенесена полностью; Beamer остаётся
содержательным эталоном до принятия автором. Правила и журнал решений:
[MIGRATION.md](MIGRATION.md).
Таблица соответствия и проверки: [Lecture 1 migration](lecture01-migration.md).

## Запуск

Требуется **Node 24.19.0** (см. `.nvmrc`). Версии зависимостей зафиксированы
общим `package-lock.json`; не устанавливать зависимости отдельно для лекций.

```sh
cd slidev
npm ci
npm run dev
```

Открыть `http://localhost:3031/`. Исходник — `lecture01.md`.

- Режим преподавателя: `http://localhost:3031/presenter/1`.
- Обычный полноэкранный показ с закреплённой панелью пера:
  `http://localhost:3031/1?tools`.
- Arrow Right / Space — следующий шаг; Arrow Left — предыдущий.
- В панели есть отдельные кнопки переходов: ими можно пользоваться при включённом пере.
- Сервер по умолчанию доступен только с этого компьютера. Подключение отдельного
  планшета по сети требует отдельно настроенного и разрешённого сетевого режима.

## Материалы и проверка

```sh
npm run check
npm run test:demos
npm run build
npm run export
```

Результаты: `dist/lecture01/`, `output/pdf/lecture01-handout.pdf` (44 страницы),
`output/pdf/lecture01-steps.pdf` (89 страниц). Для build/export остановить dev,
после завершения снова запустить его: Slidev использует общие generated-файлы
в `node_modules/@slidev/client`.

Экспорт ищет установленный Chrome или Yandex. Другой Chromium можно задать
переменной `SLIDEV_BROWSER_PATH`. Чистые PDF создаются в свежем процессе с
`drawings.persist: false`; панель инструментов в PDF не выводится.

Для проверки в браузере при работающем dev-сервере:

```sh
node tools/inspect.mjs
node tools/inspect-demos.mjs
```

Для рендера контактных листов PDF: `python tools/render-qa.py` в среде с
`pypdf`, `pypdfium2`, `Pillow`. Эти библиотеки нужны только для проверки,
не для показа лекции. Результаты проверок хранятся в игнорируемой `output/qa/`.

## Пометки занятия

Панель доступна постоянно в presenter mode или с `?tools`, без hover.
**Pen**, четыре цвета, **Undo**, **Redo**, **Save**, **Restore**, **Save & clear**.
Кнопки имеют область касания не менее 44 × 44 CSS px при масштабе 1.

- **Save** скачивает отдельный JSON со SVG-пометками всех слайдов. Сохранить
  его вместе с версией исходника лекции, использованной на занятии.
- **Save & clear** сначала скачивает архив сессии, затем очищает текущий слайд.
  Проверить загрузку файла перед закрытием браузера; браузер может блокировать
  автоматические скачивания. Остальные слайды сохраняются.
- **Restore** проверяет формат, название лекции, число слайдов и допустимое
  содержимое SVG. Если уже есть пометки, сначала скачивает текущую сессию,
  затем восстанавливает загруженную. SVG-архив не содержит историю Undo/Redo:
  после Restore она начинается заново, старые штрихи можно очистить целиком.
- Пометки относятся к логическому слайду и сохраняют координаты при раскрытиях.
  После изменения текста или геометрии слайдов старый архив может не совпасть:
  название и число слайдов не являются проверкой версии содержания.
- Постоянное автосохранение в исходник отключено. До закрытия страницы или
  остановки сервера нужно нажать Save. `sessions/` исключена из Git.
- Статическая сборка не предоставляет сервер для синхронизации разных устройств.
  Проверка реального пера, проектора и сетевой схемы ещё нужна.

## Общие ресурсы

- `style.css`, `global-top.vue`, `components/CourseTools.vue` — общая тема и панель.
- `setup/macros.json` — генерируемый адаптер из `lectures/utils/newcommands.tex`.
  После изменения обозначений: `node tools/sync-notation.mjs`.
- `public/lecture01/` — точные копии исходных иллюстраций; `npm run check`
  проверяет их хеши. Изменять оригинал и синхронизировать копию явно.
- `public/shared/taxonomy*.svg` — экспорт исходного TikZ.
  Повторить: `tools/export-taxonomy.sh` (TeX Live + dvisvgm).
- `lecture01-map.json` — номера исходных frames, новых слайдов и кликов.
  Обновлять вместе с Markdown; `npm run check` проверяет соответствие.

Прототипы `presentation-experiments/lecture08-guidance/` сохранены в ветке
`codex/lecture01-interactivity`; в `main` они не включены. Новые лекции
используют этот общий проект.

## Интерактивная Lecture 1

- [Гистограмма](http://localhost:3031/29): 10 / 100 / 1000 / 10000 точек, Sample и Reset.
- [Авторегрессия](http://localhost:3031/39): режим Generate / Evaluate, Next pixel
  и Start over / Another image. Повторное нажатие активного режима сохраняет шаг.

Начальное состояние сохранено: `codex/slidev-before-interactivity`, `1446c57`.
Эксперимент: `codex/lecture01-interactivity`. Гистограмма возвращена к одному
исходному слайду с тремя раскрытиями: изменена только иллюстрация. Sample
выбирает категорию по её частоте и подсвечивает столбик. Размер выборки меняет
частоты по первым n точкам одной воспроизводимой последовательности; шкала
вертикальной оси постоянна. Reset возвращает n = 1000 и сбрасывает выбор.
KL-демонстрация [сохранена для лекции 5 о GAN](deferred-demos.md).
Сравнение исходников:

```sh
git diff codex/slidev-before-interactivity...codex/lecture01-interactivity -- slidev
```

Чтобы вернуться к исходной версии, остановить dev-сервер, переключиться
`git switch codex/slidev-before-interactivity` и снова запустить его.
Перед переключением сохранить свои незакоммиченные правки.

Демонстрациями управлять в окне, которое выводится на экран: состояние виджетов
между отдельными presenter/viewer не синхронизируется. Для PDF предусмотрены
статические примеры. Подробный сценарий и ограничения — в журнале миграции.
