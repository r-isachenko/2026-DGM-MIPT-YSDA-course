## Исходные оговорки, сохранённые без исправления

Это наблюдения при переносе, не новый аудит курса и не автоматически принятые
редакторские задачи:

- Log-derivative: в формулировке явно не указано условие p(x)>0.
- Jensen / Monte Carlo / LOTUS: существование соответствующих ожиданий и
  условия интегрируемости подразумеваются; не дописывались при миграции.
- Dirac delta показана привычной нестрогой записью как «плотность» со значением
  +∞ в нуле; распределение не является обычной функцией.
- MNIST описан как grayscale, а пример использует {0,1}: исходная оговорка
  сохранена. Рассуждение о числе параметров относится к бинаризации.
- MLP: фраза “becomes intractable” для длинной истории и граничные индексы j<d
  сохранены. В примере не задано явное отображение h_j → π_j; оно не добавлялось.
- Устаревающие примеры моделей, состав команды, 14 лекций и правила оценивания
  взяты из исходника. Внешняя актуализация содержания не входила в перенос.

| 41 | Sample / Evaluate, Next pixel, New sample / Next example, Reset | Полная картинка, девять условных вероятностей и их произведение |

Данные локальны: фиксированная выборка из семейства горизонтальных/вертикальных
полос, без нейросети. Совместная модель использует эмпирические условные вероятности
без сглаживания. Оранжевая рамка обозначает нарушение структуры полос; это не
проверка совпадения с конкретной картинкой обучающей выборки. Отдельные параметры
в каждой позиции дают числа 2^m−1, m, 2m−1. Случайные потоки воспроизводимы;
Reset возвращает исходную последовательность сэмплов.

Forward KL для одной гауссианы минимизируется совпадением среднего и дисперсии;
reverse KL вычисляется численным интегрированием и минимизируется численно из
нескольких начальных точек. Это пример при ограниченном семействе моделей,
а не универсальное утверждение о поведении KL.

Сценарии преподавателя записаны в заметках соответствующих слайдов; ориентир —
1 + 2 + 1–2 + 2 минуты вместо соответствующих устных примеров. Новый материал
не требует менять Summary или рекап L2: определения, MLE, AR-факторизация,
Sampling и разделы не изменены. Проверки notation/recap/summary/README не
обнаружили новых рассогласований.

Окно показа хранит состояние виджетов при соседних переходах. Состояние
виджетов не синхронизируется между отдельными окнами presenter/viewer:
для живой демонстрации управлять самим окном, выводимым на экран.
PDF использует отдельные фиксированные состояния; чистый экспорт не содержит
панели управления и пометок. Реальные планшет, стилус и проектор ещё требуют
проверки, как и до этого эксперимента.

## Терминология операций модели

По решению автора: Sampling (generation) — получение нового объекта;
Density evaluation — вычисление p(x) для заданного объекта; Density estimation —
обучение распределения по данным. В постановке задачи, AR-демонстрации и Summary
используются эти значения. В обзоре приложений сохранено обычное «image/video
generation», в цитатах — исходные названия. Оценка качества называется
model quality evaluation.

«32 synthetic» было актуальным описанием выборки, а не остатком старой версии:
32 наблюдения 3×3 содержат 10 различных узоров, с повторами. Подпись заменена
на понятное описание учебных данных, число примеров теперь берётся из data.length.
Слайд 41 и кнопки демонстрации используют Sampling / Density evaluation.
Постановка задачи теперь различает неизвестное распределение данных и изучаемую
модель p(x). Beamer и Recap L2 оставлены без правок по ограничению «только Slidev»;
при переносе L2 следует принять эту терминологию в его Recap.

Проверки терминологии: finalize успешен, 7 тестов пройдены; обе PDF обновлены
(46 / 91 страниц). Изменённые слайды и Summary просмотрены; браузерные проверки
слайдов 4, 6, 8, 30, 41, 46, пометок и 12 состояний демонстраций пройдены.
