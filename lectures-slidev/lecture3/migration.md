### Модель и управление

- ELBO рассчитан для нормированной модели `z ~ N(0, 1)`, `x | z ~ N(z, 1)` при наблюдении `x = 2`. Точный posterior — `N(1, 1/2)`, где второй параметр — дисперсия. ELBO вычисляется через ожидаемый log-likelihood минус KL к prior; тождество с KL к posterior проверяется отдельно. Изменение вариационного распределения не меняет evidence.
- Reparametrization использует воспроизводимый генератор Box–Muller с исходным seed `53`. Только Resample noise меняет выборку. Reset восстанавливает seed `53`, μ = 0, σ = 1. Контрольные производные: `∂z/∂μ = 1`, `∂z/∂σ = ε`.
- Общая существующая панель `DemoPanel` изолирует события управления от переходов Slidev и слоя пера. Состояние компонентов в памяти сохраняется при уходе на соседний слайд и возврате. В PDF для каждого демо одновременно показаны три подготовленных примера; раскрытия пути градиента остаются пошаговыми.
- Управлять демо нужно в выводимом на экран окне. Произвольное состояние этих компонентов между presenter/viewer не синхронизируется. После полной перезагрузки страницы значения возвращаются к исходным.
